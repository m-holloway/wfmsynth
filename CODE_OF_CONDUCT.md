# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org), version
2.1, as its code of conduct. The canonical text is at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.

It is adopted by reference rather than copied here so that it cannot drift from the canonical
wording — this file is not the authority on what it says, that link is.

## In short

Participate in a way that makes other people want to keep participating. Harassment, personal
attacks, and demeaning or exclusionary behaviour are not acceptable in issues, pull requests,
commit messages, or anywhere else this project is discussed.

## A note specific to this project

Much of the review here is about *measurements* — whether a number is right, whether a claim is
supported, whether a change moved rendered output. Expect that scrutiny, and apply it to the
work rather than to the person doing it. "This is wrong and here is the measurement" is the
culture. "You are careless" is not.

Being confidently wrong is normal and fine; several entries in `BACKLOG.md` document changes
that were implemented, measured, and backed out. Saying "I measured it and I was wrong" is a
contribution, not an embarrassment.

## Reporting

Report conduct concerns privately to the maintainer through GitHub — open a
[security advisory](https://github.com/m-holloway/wfmsynth/security/advisories/new) if you need
a private channel and no other is available, or contact the maintainer via their GitHub profile.
Reports will be handled discreetly. The maintainer is the sole enforcer of this policy, which
means a concern *about* the maintainer has no internal route; raise it publicly or take it to
GitHub if you judge that necessary.
